# maxsilverman9.github.io

Personal research site. A live, in-browser demonstration of a drawdown-controller
failure mode from *Survival, Not Growth* (SSRN, 2026): a position-sizing rule
that reaches exactly zero exposure freezes permanently, even through a full
market recovery. Static site, no backend — the simulation runs client-side
against real historical S&P 500 data.

Links to both working papers and their companion repositories are on the page.
